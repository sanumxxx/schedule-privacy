«Расписание в вузе» (com.sanum.schedule) — reference for support and import

The app is not tied to any specific university, company, or website. Users add their own iCalendar (.ics) URL or enter classes manually. Any HTTPS host that serves a compatible .ics file may be used.

Calendar format (Russian UI, standard iCalendar):
https://sanumxxx.github.io/schedule-privacy/calendar-format.html

Sample calendar to import:
https://sanumxxx.github.io/schedule-privacy/calendar.html
Direct file: https://sanumxxx.github.io/schedule-privacy/sample-calendar.ics

Typical VEVENT fields:
- SUMMARY: discipline and lesson type in parentheses
- DESCRIPTION: lines starting with Группа: and Подгруппа:
- LOCATION: room
- DTSTART / DTEND with timezone

No login, in-app purchases, shared user content, or developer-hosted backend. Network is used only when the user submits a calendar URL.

Support: https://sanumxxx.github.io/schedule-privacy/
