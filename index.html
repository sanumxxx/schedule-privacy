Универсальное приложение для расписания занятий и личного журнала преподавателя. Не привязано к конкретной организации — пользователь сам указывает источник (.ics) или вводит пары вручную.

О приложении

Показывает расписание на выбранный день, виджет, напоминания за 15 минут до пары. Для преподавателя — журнал по группам (посещаемость, оценки, пересдачи). Аккаунта и сервера разработчика нет.

Данные на устройстве

  • расписание из .ics или ручного ввода;
  • роль: студент или преподаватель;
  • списки студентов и отметки журнала;
  • настройки и уведомления.

Данные остаются на iPhone. Разработчик их не получает.

Сеть

Запрос по сети выполняется только когда пользователь сам вставляет URL файла .ics. Запрос идёт на хост из ссылки, не к разработчику. Рекламы и аналитики нет.

Удаление данных

Удалите приложение с iPhone — вместе с ним удалятся все локальные данные.
