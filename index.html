О чём это приложение

Приложение показывает расписание занятий и, для преподавателя, ведёт журнал: списки студентов, посещаемость, оценки и пересдачи. Аккаунта в приложении нет.

Какие данные хранятся

На устройстве могут храниться:

  • расписание, которое вы ввели вручную или загрузили из файла календаря;
  • выбранная роль: студент или преподаватель;
  • списки студентов, отметки посещаемости, оценки и пересдачи;
  • настройки приложения и расписание уведомлений о парах.

Эти сведения остаются на вашем iPhone и в виджете приложения. Разработчик их не получает и не хранит на своём сервере.

Что передаётся по сети

Сеть используется только если вы сами указываете ссылку на файл календаря или открываете такой файл. Приложение запрашивает этот файл по адресу, который ввели вы. Запрос уходит на сайт из ссылки, а не разработчику.

Разработчик не добавляет в приложение рекламу, счётчики аналитики и не продаёт данные.

Уведомления

Напоминание о паре создаётся на самом устройстве. Для этого приложению нужно разрешение на уведомления. Текст напоминания на сервер разработчика не отправляется.

Как удалить данные

Удалите приложение с iPhone. Вместе с ним удаляются расписание, журнал и списки, сохранённые в приложении.

Дети

Приложение не предназначено для детей младше 13 лет и сознательно не собирает их данные.

Изменения

Если политика изменится, новая версия будет опубликована на этой странице с новой датой.
